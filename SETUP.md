# Локальная настройка

Нужны Node.js 22+ и PostgreSQL 16+.

1. Установите зависимости: `npm install`.
2. Скопируйте `.env.example` в `.env`. Не коммитьте `.env`.
3. Создайте пустую PostgreSQL-базу и заполните `DATABASE_URL`.
4. Сгенерируйте клиент: `npx prisma generate`.
5. Создайте миграцию: `npx prisma migrate dev --name init`.
6. Запустите `npm run dev` и откройте `http://localhost:3000`.

Для просмотра только демонстрационного интерфейса база пока не требуется.

## Секреты

`AUTH_SECRET` и `CRON_SECRET` — разные случайные строки не короче 32 байт. `ENCRYPTION_KEY` — base64-представление 32 случайных байт. Не отправляйте ключи в чат и не вставляйте их в исходный код.
