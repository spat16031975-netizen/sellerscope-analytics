# Тестирование

## Автоматические проверки текущего инкремента

```bash
npm test
npm run lint
npm run build
npx prisma validate
```

Покрыто: деление на ноль, отсутствие входных данных, ДРР/ROAS/маржа, запрет подмены организации и запрет записи наблюдателем.

## Обязательные проверки перед production

| Сценарий | Проверка |
|---|---|
| Вход/выход | ротация сессии, Secure cookie, отзыв всех сессий |
| Изоляция | пользователь A не читает и не меняет сущности B через URL, body и export |
| Первичная загрузка | полный доступный период, курсоры, контроль количества |
| Повтор | второй запуск не создаёт дубликаты |
| 429 | учитывается `Retry-After`, job не теряется |
| 5xx/timeout | экспоненциальная задержка с jitter, ограничение попыток |
| Просроченный токен | Connection → EXPIRED, понятное уведомление, история сохраняется |
| Неполные данные | `null`, предупреждение, прибыль не показывается |
| Формулы | выборочная сверка минимум 20 операций с ЛК |
| Фильтры | KPI, график и таблица используют одинаковое окно и timezone |
| Railway restart | активная lease истекает, job безопасно подхватывается снова |
| Мобильный UI | 360, 390, 768 px; нет горизонтального переполнения страницы |

## Fixtures

Fixtures не содержат реальные токены, имена покупателей или персональные данные. Для каждого метода хранится минимальный обезличенный ответ и edge cases: пустая страница, `null`, late correction, возврат, неизвестный enum.

Интеграция не называется проверенной, пока нет разрешённого live-запроса и сверки с кабинетом продавца.
