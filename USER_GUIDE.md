# Руководство пользователя

## Пустой шаблон

До загрузки отчёта все показатели равны нулю, а таблицы показывают пустое состояние. В интерфейсе нет вымышленных продаж, товаров, кампаний или уведомлений.

## Навигация

Верхняя панель переключает магазин Ozon или Wildberries и задаёт месяц сразу для всего итогового листа. Доступны «Октябрь 2026», другие месяцы и режим «Все данные». Данные площадок и периодов не смешиваются. Все KPI, графики и таблицы расположены на одной прокручиваемой странице. Боковое меню на компьютере и нижнее меню на телефоне прокручивают лист к выбранному разделу.

## Импорт выгрузок

Откройте раздел «Источники данных», выберите «Загрузить отчёты» и перетащите файлы в область загрузки. Поддерживаются CSV, JSON и XLSX. Файлы разбираются локально в браузере и не отправляются на внешний сервер. Месяц определяется по столбцу с датой или имени файла; при необходимости его можно изменить в колонке «Период отчёта». Для каждого магазина сохраняется отдельная история: количество строк, заказов и найденная выручка автоматически появляются в сводке выбранного месяца.

После обновления анализатора ранее сохранённые записи нужно один раз загрузить повторно: браузер хранит рассчитанную сводку, но не имеет права заново открыть исходный локальный файл. Повторная загрузка файла с тем же именем заменяет старую запись и не создаёт дубль. Для отчётов Ozon распознаются продажи по дням, товары и SKU, остатки, рекламные кампании, расходы, показы, клики, ДРР и ROAS.

## Подключение API

В разделе «Источники данных» выберите «Подключить API». Для Ozon понадобятся `Client-Id` и `Api-Key`, для Wildberries — API-токен. Ключ передаётся серверному маршруту только для проверки официальным API площадки и не сохраняется в браузере. Для постоянной автоматической синхронизации production-версия должна хранить секрет в зашифрованном хранилище и запускать отдельный worker.

## Как читать показатели

- «Заказы» — размещённые заказы, а не продажи;
- «Реализовано» — подтверждённые площадкой продажи;
- «Выручка» учитывает подтверждённые возвраты;
- «Управленческая прибыль» появляется только при полной себестоимости и расходах;
- «Не рассчитывается» означает, что данных недостаточно или знаменатель равен нулю.

## Подключение магазина

Откройте «Настройки» → «Подключить магазин». Для Ozon коммерческий вариант использует OAuth: продавец подтверждает права на официальной странице Ozon. Ключи не нужно передавать владельцу SellerScope в переписке.

## Если данные устарели

Проверьте время последней успешной загрузки. В «Настройки → Обновления» откройте журнал. При просроченном токене система предложит переподключение; исторические данные не удаляются.

## Себестоимость

В «Финансы» загрузите Excel/CSV с seller SKU, датой начала действия, суммой и валютой. Новая цена не перезаписывает историю, а действует с указанной даты.
